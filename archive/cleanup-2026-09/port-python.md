# Porting `fix/rivals-osdk-pregame` (Python) to the C# server

Analysis of 2026-09-25. Python branch: `origin/fix/rivals-osdk-pregame` at `29196b7`. C# branch: `feat/local-c-sharp-fut` at `c93d601`. Treat the Python branch as reference material: copy behaviour and client contracts, never its structure. Every port gets a C# test, and client-visible changes need a live check.

## How the baseline was found

- The branches split at `1267ddc` (2026-09-05). The Python branch is 140 commits ahead: 116 touch `server.py` and the rest are docs and tools.
- The C# server was ported on 2026-09-14 (`439e395`) from this repository's own Python fork. Its last `standalone-server/.../server.py` (`daaf3c0`, 2026-09-13) is closest to Python `aca41ba` (2026-09-13), with about 1,220 lines of our own changes on top. On 2026-09-15, `61ac303` ("shadow's fixes") brought later Python rule data into `rules/*.json`.
- So the candidates are the Python commits from `aca41ba` onward. Each was checked against the C# sources by the identifiers it introduced, and ambiguous ones by reading its diff or message body. **Observed** means seen in code or in the commit. **Inferred** means read from code but not tested.
- **Rivals evidence:** `17172fc` (2026-09-23/24) reports Rivals matches **played to full time live**, with the retail squad check on. Most Rivals commits from 2026-09-15 to 2026-09-20 are experiments behind flags (default off); `17172fc` retired several, and the 2026-09-22 VPS sync (`2f46d8d`) dropped code that never ran in production. Port the **final production behaviour**, not every experiment.
