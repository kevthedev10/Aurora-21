# Fonts (self-hosted: the panel's CSP allows fonts from 'self' only)

- `barlow-condensed-latin{,-ext}-{600,700}-normal.woff2`: Barlow Condensed, SIL Open Font License 1.1
  (`BarlowCondensed-OFL.txt`), taken from the npm package `@fontsource/barlow-condensed` 5.3.0. It is the display
  face: page titles, ratings, coin and point figures.
- `plexsans.woff2` (variable, 100–700) and `plexmono-400.woff2`: IBM Plex Sans and Mono (SIL OFL 1.1), copied
  from the original Aurora16 panel at commit `027a5c1` (2026-09-25), with maintainer authorization.
  They are retained in this React source directory for interface text and IDs/logs.
